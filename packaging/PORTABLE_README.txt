RimWorld Translation Editor 0.4.0
RimWorld Translation Editor (multi-language translation editor for RimWorld MODs)

Windows: Extract the complete ZIP (right-click, Extract All), then double-click
         RimWorldTranslationEditor.exe in the extracted folder.
Linux:   Extract the complete tar.gz with an archive manager, then run
         RimWorldTranslationEditor in the extracted folder.
         If it does not start: chmod +x RimWorldTranslationEditor
                               ./RimWorldTranslationEditor

Python is bundled; no separate Python or Git installation is needed for everyday use.
You need to provide RimWorld itself and the source MODs on your own PC.
Do not move the executable alone: keep the whole folder, including _internal/ and
licenses/. Keep your saved translation projects outside this application folder
(for example in your Documents folder); after an app update you can still open
them from there.
